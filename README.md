This is planned be a crypography library using the Low* subset of F*, like a smaller HACL*

KaRaMeL can't compile any code that isn't Low* so only well-typed, correct, strong(hopefully) C code is generated.

I have released a binary which I highly recommend downloading instead of building from source to save yourself the pain of building F* with KaRaMeL.
